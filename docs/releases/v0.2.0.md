# 自动音频字幕 v0.2.0

新增缅文批量整理，接入现有音频和 SRT 生成流程。

- A 列放原始缅文，AI 整理结果自动写入 B 列；C 列填写项目名称。
- 通过登录后的 Google AI Studio 免费文本模型整理，无需 API Key。
- 每条文案新建临时会话，清空上一条上下文；正确读取最终正文并保留字幕换行。
- 支持选择多个浏览器窗口中的 AI Studio 标签页，批次固定使用所选页面。
- 支持整理全部、整理所选、请求间隔、回复超时和停止整理。
- 已断行的文案可直接粘贴到 B 列，使用原有音频生成，无需连接 AI。
- 更新依赖、强化消息校验和 CI／发布工作流。

## 安装与更新

1. 下载附件 `auto-audio-subtitles-v0.2.0.zip`，解压到固定文件夹。
2. 在 Microsoft Edge 打开 `edge://extensions`，开启开发人员模式。
3. 选择“加载解压缩的扩展”，选中解压后包含 `manifest.json` 的文件夹。
4. 更新已有安装时替换扩展目录中的文件，再点击“重新加载”，重新打开工作台并刷新 AI Studio 页面。

ZIP 由此版本标签触发 GitHub Actions 自动构建，包含全部运行资源、字体、FFmpeg/WASM 与许可证。最终用户无需安装 Node.js 或 Python。附件 `SHA256SUMS.txt` 用于检查下载文件完整性。
