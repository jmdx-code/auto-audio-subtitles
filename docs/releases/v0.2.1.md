# 自动音频字幕 v0.2.1

- 修复微软语音服务更新认证协议后返回 403、音频生成一直停在 2% 的问题，改用 Sec-MS-GEC v2。
- 移除过时的 edge-tts-universal 及其间接依赖，改为插件本地的原生 WebSocket/fetch 实现。
- 补齐连接失败、连接提前关闭、无音频、数据异常及超时处理；失败会进入现有重试流程。
- 取消批量任务与停止试听会中止正在进行的语音请求并释放连接。
- 保留原有文案整理、音频合并与连续字幕生成流程。

验证：67 项自动化测试通过；Edge 本地 HTTP 页面实测音色列表、缅文语音生成、静音裁剪、MP3 合并及连续 SRT 输出通过。

更新后在 Edge 扩展管理页重新加载插件，再重新打开工作台。工作台刷新会清空尚未生成的文案，请先另行保留。
